# Session Resume — 2026-06-10

_I/O simulation layer, feedrate-true playback, and the ATC generator rebuild.
Two commits pushed to `main`: `8b49ba3` and `357d61d`._

---

## Why

Users on socials (e.g. Christopher Barragan) asked to **test macros that wait on
controller inputs/outputs** — a tool-change that waits for the spindle ATC sensor —
*before* installing them on the machine. SIMULATION-NOTES.md had this as the open
"I/O state-stepping" item. Decision made this session: build the I/O logic layer now,
**machine-frame mode stays deferred**.

## Commit 1 — `8b49ba3` · I/O simulation layer + feedrate-true playback

### Floating Virtual I/O panel (`web/ui/ioTab.js`, rewritten)
- Draggable, **resizable** (flex LED grid reflows), position/size persisted.
- 24 click-to-toggle inputs + 24 live outputs. Replaces the Settings → I/O tab.
- Toggled by the **I/O** button in the 3D drawer; **auto-shows** when execution
  parks on a sensor wait, with the waited pin **pulsing** and a banner
  ("⚠ Waiting for IN12 … click to satisfy").

### Execution engine (`web/engine/GcodeExecutionEngine.js`)
- **⏭ Step** (one line per click) · **▶ Run / Resume / ⏸ Stop**.
- `M31/M33` waits park execution instead of skipping/hanging blind.
- **Auto sensors** (default ON): any waited input is answered by a virtual sensor
  after ~0.8 s — even pins the truth table doesn't know — so *any* pinout completes
  hands-free. Turn OFF to hand-drive sensors and exercise `IF/GOTO` fault branches.
- **Feedrate-true playback**: every move interpolates over `distance ÷ F`
  (rapids at 6000 mm/min) — slow probes crawl, rapids zip. **Speed** selector
  (1× / 2× / 5× / 10× / MAX), changeable mid-move. Status shows
  `G31 probe 10.0 mm at F50 — 12.0 s`.
- **⟳ Loop** toggle: auto-restart on completion (continuous Run only).

### 3D preview (`web/viz/gcodeViz3d.js`)
- ▶ Play loop animation is now **feedrate-proportional** (segment time ∝ length/F).
- **Beeper fix**: the loop no longer beeps every ~5 s forever; one beep when an
  engine run completes.
- **MMB pans, Shift+MMB orbits** (CAD-style).

### Real bugs fixed
1. **Pin-name mismatch** — the old I/O board injected numeric pins while `M31 P5`
   polls resolved names (`IN_DRAWBAR_CLOSED`); manual clicks never unblocked waits.
2. **Stale handshake leak** — `resetVirtualIO()` now cancels in-flight truth-table
   timers (a previous run could flip a sensor mid-way through the next run).
3. **Probe pin never flipped** — `G31` contact now pulses the actual probe input
   (the `P` pin, or the configured IN3) at the moment the paced move reaches contact.

## Commit 2 — `357d61d` · ATC generators rebuilt on the real DDCS dialect

### The discovery
The old tool-change generator's I/O approach was fiction: on a real DDCS Expert,
**`M10/M11` is the LUBRICATION output** (param #1233). The controller's actual ATC
model, decoded from `Variables-ENG 01-04-2025.csv`:

| Concept | DDCS reality |
|---|---|
| Drawbar release / lock | `M154` / `M155` (output port = param #1250) |
| Sensor waits | `M300` spindle-stopped · `M302` locked · `M303` open · `M304` closed |
| Dust cover | `M305` / `M306` |
| Pocket positions | tables `#1330+`(X) `#1350+`(Y) `#1370+`(Z), machine coords |
| Target / current tool | `#1504` (set by `M6 Txx`) / `#1300`, capacity `#1301` |
| `G4 P` unit | **milliseconds** |

### Generators (ATC menu)
- **🔧 Tool Change** (was mislabeled "Carousel Align") — two modes:
  - *Manual*: park + operator swap prompt (no-ATC machines like the Ultimate Bee).
  - *Auto*: full **T.nc-style pick & place** — validate target, same-tool
    short-circuit, spindle-stop wait, put away old tool, pick up new one, sensor
    verification at each step, `#1300` bookkeeping, error handlers. Options:
    dust cover, confirm prompt, fixed test tool. Save as `T.nc` to hook `M6`.
- **🧪 ATC Test** (new wizard) — commissioning checks run *before* the first change:
  - *Drawbar cycle test*: N release/lock cycles, both sensors verified per cycle —
    a sticky valve/sensor shows up as a hang on the exact wait.
  - *Pocket dry-run*: visit every taught pocket at clearance (optional descend),
    pause for visual alignment check. No tool, no drawbar.
- **🔥 Warm-up fix**: was dwelling **30 ms instead of 30 s** — seconds now
  converted to ms.

### Engine speaks the same dialect
`M154/155` + sensor handshakes in the virtual-I/O truth table, `M3/M5` drive a
spindle-stopped sensor, `G4` dwell paced (ms, scaled by sim speed), `M6` stores
`#1504` — so **every generated macro runs end-to-end in the 3D drawer** before
touching the machine.
